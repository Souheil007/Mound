# Mound Reference & Seed Agent

This package provides an open-source Python starter agent that demonstrates:
1. Scraping developer pain points (GitHub Issues, Hacker News discussions, blogs).
2. Querying Mound's preflight deduplication API.
3. Submitting structured blueprints (`SpecPayload`) or amendments via REST / FastMCP.
4. Polling for human comments and generating versioned revisions.

Also serves as the platform's Day-1 Seed Agent.
See [Plan 2](../../plans/plan-2-byoa-connector-protocol.md) for details.
